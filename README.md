# GTO Wizard ブログ記事マップ

GTOウィザードの公式ブログ（[blog.gtowizard.com](https://blog.gtowizard.com/)）の記事を
全部まとめて取ってきて、カテゴリ別に整理した一覧ページを作るツールです。
定期的に実行すると、前回から**新しく出た記事**が「新着」として表示されます。

## 使い方

ターミナルで以下を実行するだけです。

```
cd ~/GTO勉強/gtow_blog
python3 update.py --open
```

これで最新の記事を取り直し、`記事一覧.html` を作り直してブラウザで開きます。
`--open` を付けなければページを更新するだけです（あとから自分で開けます）。

できあがった `記事一覧.html` はダブルクリックでもいつでも開けます。
ブックマークしておくと便利です。

## 携帯で見る

公開済みのURLがあります（**非公開設定なので、あなた以外は見られません**）。

https://claude.ai/code/artifact/e44076d0-c811-41f8-9e00-f1b2f96f7cce

携帯のブラウザで開いてホーム画面に追加しておくと、アプリのように使えます。
画面が狭いときは、左のカテゴリ一覧がプルダウンに切り替わります。

このURLの中身は**公開した時点のスナップショット**です。`update.py` を実行しても
自動では更新されないので、新着を携帯側にも反映したいときは Claude に
「携帯用を更新して」と頼んでください（同じURLのまま中身が差し替わります）。

## 毎週の自動チェック（設定済み）

**毎週月曜の9:07に自動で実行**されるように設定してあります。何もしなくても
[記事一覧.html](記事一覧.html) は最新に保たれ、新着があればMacの通知で知らせます。

- その時刻にMacが寝ていた場合は、次に起動したときに実行されます
- Macの電源が入っていない週はスキップされますが、次の実行でまとめて拾います
- 実行結果は `data/自動実行.log` に残ります

**止めたいとき**は [自動実行/解除する.command](自動実行/解除する.command) をダブルクリック。
**再開したいとき**は [自動実行/設定する.command](自動実行/設定する.command) をダブルクリックです。
時刻を変えたい場合は `自動実行/com.gtow.blogmap.plist` の `Weekday`（1=月曜）と
`Hour` / `Minute` を書き換えて、設定する.command をもう一度実行してください。

なお、**携帯用URLは自動更新の対象外です**（更新にはClaudeを経由する必要があるため）。
新着を携帯にも反映したいときは Claude に「携帯用を更新して」と頼んでください。

## 一覧ページでできること

- **左のカテゴリ一覧**でクリックすると、そのカテゴリの記事だけ表示
- **🆕 新着**：直近30日以内に新しく出た記事だけ表示
- **✏️ 更新あり**：既存記事の内容が書き換えられたものを表示
- **検索窓**：タイトルと本文冒頭から検索
- **並び替え**：公開日の新旧、読了時間の長短、タイトル順
- 記事タイトルをクリックすると元記事が新しいタブで開きます

「すべての記事」を選んでいるときは、大分類（フォーマット別／理論・戦略／対人・実戦／
学習ガイド／運営・お知らせ）ごとに章立てして表示します。

## 「これから出る記事」について

GTOウィザード側の**予約投稿は外部から取得できません**（公開APIは公開済みの記事しか
返さない仕様です）。そのため本ツールは「実行するたびに前回との差分を取り、
新しく公開された記事を検出する」方式で未来の記事を追いかけます。

つまり **実行しないと新着は溜まりません。** 週1回くらい実行するのがおすすめです。

## ファイルの中身

| ファイル | 役割 |
| --- | --- |
| `update.py` | 実行するのはこれ。取得 → 差分検出 → ページ生成 |
| `fetcher.py` | ブログから記事データを取ってくる |
| `store.py` | 前回のデータを保存し、新着・更新・削除を判定 |
| `renderer.py` | 一覧ページのHTMLを組み立てる |
| `categories.py` | カテゴリの日本語名と大分類の定義（**編集するならここ**） |
| `記事一覧.html` | できあがる一覧ページ |
| `data/posts.json` | 全記事の記録。**消すと新着判定がリセットされます** |
| `data/history.jsonl` | 実行するたびの記録（いつ何が増えたか） |

## カテゴリの日本語名を変えたいとき

`categories.py` を開いて `LABELS_JA` の行を書き換えてください。
大分類の並びやグループ分けを変えたいときは `GROUPS` を編集します。
GTOウィザード側で新しいカテゴリが増えた場合、定義がなくても自動で
「その他」グループに英語名のまま表示されるので、放置しても記事が消えることはありません。

## 制約・注意点

- 取得できるのは**公開済みの記事のみ**。予約投稿・下書きは見えません。
- 「新着」の判定は**このツールを実行したタイミング**が基準です。実行が空いた期間に
  出た記事は、次に実行した日にまとめて新着として出ます。
- 記事の公開日が過去に遡って設定された場合、公開日順では下の方に出ますが、
  新着判定（🆕）は正しく効きます。
- `data/posts.json` を消すと「初回実行」扱いに戻り、その時点の全記事が基準に
  なります（新着は0件からやり直し）。
- 動作に必要なのは Python 3 のみ。追加インストールは不要です。
