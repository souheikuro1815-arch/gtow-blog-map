# GTO Wizard ブログ記事マップ

GTOウィザードの公式ブログ（[blog.gtowizard.com](https://blog.gtowizard.com/)）の記事を
全部まとめて取ってきて、カテゴリ別に整理した一覧ページを作るツールです。
定期的に実行すると、前回から**新しく出た記事**が「新着」として表示されます。

## 使い方

**普段はこのURLを開くだけです。設定や実行は必要ありません。**

https://souheikuro1815-arch.github.io/gtow-blog-map/

手元のMacで動かしたいとき（カテゴリ分けを変えて試すなど）は、ターミナルで
以下を実行すると `記事一覧.html` が作られます。

```
cd ~/GTO勉強/gtow_blog
python3 update.py --open
```

## 見る（携帯・パソコン共通）

**https://souheikuro1815-arch.github.io/gtow-blog-map/**

このURLを開くだけです。携帯でもパソコンでも見られます。画面が狭いときは、
左のカテゴリ一覧が自動でプルダウンに切り替わります。

携帯のブラウザで開いてホーム画面に追加しておくと、アプリのように使えます
（Safariなら共有ボタン →「ホーム画面に追加」）。

## 自動更新（設定ずみ・作業不要）

**毎週月曜の朝9時ごろ、GitHubのサーバー上で自動実行**されます。新しい記事が
出ていれば取り込まれ、上のURLに🆕バッジ付きで反映されます。

- **Macの電源が入っていなくても動きます**
- あなたが何かする必要はありません
- 実行の記録は https://github.com/souheikuro1815-arch/gtow-blog-map/actions で見られます

すぐに反映したいときは、上のページの「記事一覧を更新して公開」→「Run workflow」
ボタンで手動実行できます。

## 日本語版について

GTOウィザードには**公式の日本語版ブログ**があります（英語版とは別サイト）。

https://japan.gtowizard.com/blog/

日本語版があるのは英語記事364件のうち**157件（約4割）**です。一覧ページでは、
日本語版がある記事に🇯🇵付きで日本語タイトルを併記し、クリックすると日本語版が
開きます。左の「🇯🇵 日本語版あり」「未訳（英語のみ）」で絞り込めます。

検索窓は日本語タイトルも対象なので、「ICM」「ブラフ」など日本語でも探せます。

新しく日本語版が公開された記事は、毎週の自動実行で検出してログに記録されます。

## 一覧ページでできること

- **左のカテゴリ一覧**でクリックすると、そのカテゴリの記事だけ表示
- **🆕 新着**：直近30日以内に新しく出た記事だけ表示
- **✏️ 更新あり**：既存記事の内容が書き換えられたものを表示
- **検索窓**：タイトルと本文冒頭から検索
- **並び替え**：公開日の新旧、読了時間の長短、タイトル順
- 記事タイトルをクリックすると元記事が新しいタブで開きます

「すべての記事」を選んでいるときは、大分類（フォーマット別／理論・戦略／対人・実戦／
学習ガイド／運営・お知らせ）ごとに章立てして表示します。

## 「これから出る記事」について

GTOウィザード側の**予約投稿は外部から取得できません**（公開APIは公開済みの記事しか
返さない仕様です）。そのため本ツールは「実行するたびに前回との差分を取り、
新しく公開された記事を検出する」方式で未来の記事を追いかけます。

この実行は毎週GitHub上で自動的に行われるので、放っておいて構いません。

## ファイルの中身

| ファイル | 役割 |
| --- | --- |
| `update.py` | 実行するのはこれ。取得 → 差分検出 → ページ生成 |
| `fetcher.py` | 英語版ブログから記事データを取ってくる |
| `jp_fetcher.py` | 日本語版ブログを取得し、英語版と対応づける |
| `store.py` | 前回のデータを保存し、新着・更新・削除を判定 |
| `renderer.py` | 一覧ページのHTMLを組み立てる |
| `categories.py` | カテゴリの日本語名と大分類の定義（**編集するならここ**） |
| `.github/workflows/update.yml` | 毎週の自動実行の設定 |
| `記事一覧.html` | 手元で実行したときにできる一覧ページ（GitHubには保存しない） |
| `site/index.html` | 公開されるページ（自動生成。GitHubには保存しない） |
| `data/posts.json` | 全記事の記録。**消すと新着判定がリセットされます** |
| `data/history.jsonl` | 実行するたびの記録（いつ何が増えたか） |

## カテゴリの日本語名を変えたいとき

`categories.py` を開いて `LABELS_JA` の行を書き換えてください。
大分類の並びやグループ分けを変えたいときは `GROUPS` を編集します。
GTOウィザード側で新しいカテゴリが増えた場合、定義がなくても自動で
「その他」グループに英語名のまま表示されるので、放置しても記事が消えることはありません。

## 制約・注意点

- 取得できるのは**公開済みの記事のみ**。予約投稿・下書きは見えません。
- 「新着」の判定は**ツールが実行されたタイミング**が基準です（毎週月曜）。公開日が
  それより前でも、検出した日を基準に🆕が付きます。
- 🆕バッジは検出から30日で自動的に消えます。
- 記事の公開日が過去に遡って設定された場合、公開日順では下の方に出ますが、
  新着判定（🆕）は正しく効きます。
- `data/posts.json` を消すと「初回実行」扱いに戻り、その時点の全記事が基準に
  なります（新着は0件からやり直し）。
- 手元で `python3 update.py` を実行した結果は、GitHubには自動で送られません。
  手元の変更を公開ページに反映したいときは `git push` してください。
- 日本語版の対応づけはURL末尾（スラッグ）の一致で行っています。日本語版側で
  スラッグが変更されると、その記事のリンクは一時的に外れます。
- 日本語サイトが取得できなかった場合、英語版の更新だけ行い、日本語の対応づけは
  前回の内容を保ちます。
- 動作に必要なのは Python 3 のみ。追加インストールは不要です。
